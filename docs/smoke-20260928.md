# Smoke test Qwen2.5-Coder-3B — 2026-09-28

**Selesai: 3 warm-up + 24 panggilan LLM sungguhan atas fixture sintetis.**
Ini menguji jalur inferensi, parser, retrieval, pencatatan token/latency, dan resume.
Ini bukan evaluasi akurasi, bukan dev set §3.5, dan tidak memenuhi Gate G2.
Tidak ada prompt, konfigurasi penelitian, atau decision rule yang diubah.
`data/results.jsonl` tetap tidak dibuat.

## Lingkungan dan perbaikan startup

- GPU: NVIDIA GeForce RTX 5090, 32.607 MiB total menurut `nvidia-smi`.
- Python 3.12; vLLM 0.30.0; PyTorch 2.13.0+cu130.
- Model: `Qwen/Qwen2.5-Coder-3B-Instruct`, revision
  `488639f1ff808d1d3d0ba301aef8c11461451ec5`, dari cache lokal.
- bfloat16, tanpa kuantisasi, konteks 32.768, seed 0,
  `--generation-config vllm`, `--gpu-memory-utilization 0.4`.
- Request sekuensial: temperature 0, top_p 1, max_tokens 512, seed 0.
- Prefix caching aktif sesuai default server; latency di bawah hanya menggambarkan
  fixture pendek pada sesi ini, bukan benchmark RQ4 atau estimasi dataset penuh.

Log sesi sebelumnya ternyata berlanjut setelah ringkasan serah-terima: instalasi
dan unduhan bobot selesai, tetapi startup gagal pada warm-up sampler FlashInfer:
`Could not find nvcc and default cuda_home='/usr/local/cuda' doesn't exist`.
Opsi bawaan `VLLM_USE_FLASHINFER_SAMPLER=0` mengatasi kegagalan itu tanpa mengubah
kode vLLM, mengunduh bobot ulang, atau memasang CUDA toolkit sistem.

Server lokal yang berhasil dijalankan:

```bash
VLLM_USE_FLASHINFER_SAMPLER=0 HF_HUB_OFFLINE=1 .venv/bin/vllm serve \
  Qwen/Qwen2.5-Coder-3B-Instruct \
  --host 127.0.0.1 --port 8101 --dtype bfloat16 --max-model-len 32768 \
  --seed 0 --generation-config vllm --gpu-memory-utilization 0.4
```

Log pemuatan model melaporkan **5,79 GiB**. Alokasi KV cache server sebesar
4,99 GiB bukan kebutuhan minimum satu request; KV cache BF16 terhitung untuk
32.768 token adalah 1,125 GiB menurut rumus §9.3. Alokasi total `nvidia-smi`
tidak dipakai sebagai metrik memori model. Server dihentikan setelah pengujian.

## Pengamatan isi, tanpa klaim akurasi

Fixture saat ini berisi dua HN, satu MAL, dan satu TYP. Vonis yang diamati:

- `tinylint` dan `usage-kit`, keduanya berlabel benign/HN pada fixture, dinilai
  malicious oleh seluruh enam konfigurasi.
- `fmt-cli`, berlabel malicious pada fixture, dinilai malicious oleh seluruh konfigurasi.
- `date-pad`, berlabel benign/TYP, dinilai malicious pada `DIFF+I` dan `DIFF+I+MB`,
  serta benign pada empat konfigurasi lainnya. Alasan model mengaitkan penambahan
  fungsi padding angka dengan kemungkinan penyalahgunaan, tanpa bukti perilaku
  berbahaya dalam diff. Salah satu respons bahkan menyebut dua digit untuk `pad3`.

JSON yang valid tidak membuktikan alasan atau vonisnya benar. Temuan tersebut
disimpan apa adanya; tidak ada penyetelan prompt untuk membuat fixture ini lulus.
Empat pair sintetis tidak mendukung kesimpulan hipotesis, recall, atau FPR penelitian.

## Artefak dan reproduksi

Direktori [scratchpad/20260928-qwen25-smoke](../scratchpad/20260928-qwen25-smoke/)
memuat:

- [results.smoke.jsonl](../scratchpad/20260928-qwen25-smoke/results.smoke.jsonl):
  24 respons mentah beserta hasil parsing, card, token, dan latency.
- [summary.json](../scratchpad/20260928-qwen25-smoke/summary.json): ringkasan numerik dan pemeriksaan.
- [provenance.json](../scratchpad/20260928-qwen25-smoke/provenance.json): versi,

- `pairs.sample.jsonl`, `kb.sample.jsonl`, `runner.py`, `prompts.py`, `configs.py`:
  snapshot masukan dan kode inferensi yang dipakai.
- `vllm-serve.log`, `runner.log`: log server dan urutan warm-up/run.

Setelah server siap, perintah ekuivalen untuk tiga warm-up menggunakan tiga pair
pertama dan konfigurasi DIFF:

```bash
.venv/bin/python scratchpad/20260928-qwen25-smoke/runner.py \
  --model Qwen/Qwen2.5-Coder-3B-Instruct --base-url http://127.0.0.1:8101 \
  --pairs scratchpad/20260928-qwen25-smoke/pairs.sample.jsonl \
  --kb scratchpad/20260928-qwen25-smoke/kb.sample.jsonl \
  --configs DIFF --limit 3 --out /dev/null
```

Run terukur, dengan output baru bila hendak mengulang inferensi:

```bash
.venv/bin/python scratchpad/20260928-qwen25-smoke/runner.py \
  --model Qwen/Qwen2.5-Coder-3B-Instruct --base-url http://127.0.0.1:8101 \
  --pairs scratchpad/20260928-qwen25-smoke/pairs.sample.jsonl \
  --kb scratchpad/20260928-qwen25-smoke/kb.sample.jsonl \
  --out scratchpad/20260928-qwen25-smoke/results.repeat.jsonl
```

Pekerjaan berikutnya tetap penyusunan dataset nyata beserta verifikasi/anotasi,
penyelesaian normalisasi dan deduplikasi Dolos, lalu dev set 10 pair §3.5 pada
kedua model sebelum Gate G2. Smoke test ini hanya menuntaskan hambatan inferensi
lokal dan membuktikan jalur runner dapat menghasilkan artefak nyata.
