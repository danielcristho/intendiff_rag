# Dev campuran dan anotasi independen — 2 Oktober 2026

Paket **64 kandidat** siap direview: 32 kandidat MAL dari 32 kampanye berbeda
dan seluruh 32 kandidat HN D85. **Belum ada label manusia atau hasil inferensi
baru pada tahap ini.** Tujuannya menyediakan label untuk memeriksa apakah
penurunan alarm pada D85 disertai kemampuan mendeteksi update berbahaya.

## Mulai anotasi

UI lokal: **http://127.0.0.1:5174/**, backend pada `127.0.0.1:8100`.
UI menyajikan paket khusus ini, bukan seluruh 1.035 kandidat review sebelumnya.
Backend menggunakan image audit yang sudah tersedia; tidak ada paket sampel
yang dijalankan. Frontend berjalan sebagai proses lokal dan perlu dinyalakan
kembali bila sesi/mesin berhenti.

1. Dua manusia menggunakan nama anotator berbeda. Selesaikan penilaian sendiri
   sebelum melihat hasil orang lain, label sumber, atau hasil model D85.
   Nama akun hanya pemisah berkas; bukan autentikasi atau bukti dua manusia.
2. Periksa intent versi sebelum update, delta otomatis, dan smart-diff. Delta
   merupakan petunjuk otomatis, bukan ground truth. Jangan menjalankan kode,
   lifecycle script, atau URL yang ditemukan dalam sampel.
3. Tulis catatan berisi pemicu, perilaku konkret, alasan verdict, serta rujukan
   dokumentasi/kode dan kutipannya. Untuk benign, jelaskan tujuan sah dan pilih
   kategori yang sesuai. Jika bukti tidak cukup, pilih `skip` dengan alasan.
4. Untuk malicious, salin baris bukti persis dari diff ke **Gold evidence**,
   termasuk tanda `+`/`-` dan spasi. Harus ada konten perubahan; header diff saja
   tidak cukup. Kecocokan teks belum membuktikan perilaku berbahaya. Kedua
   anotator mengisi bukti secara independen sebelum pemeriksaan konsensus.
5. Isi bukti, kategori, dan catatan terlebih dahulu; pindahkan fokus agar
   tersimpan. **Pilih verdict terakhir**, karena tombol verdict maju ke sampel
   berikutnya. Gunakan filter `semua`: filter `belum direview` saat ini hanya
   menghitung keberadaan entri, termasuk catatan tanpa label. Kelengkapan akhir
   diperiksa dengan skrip di bawah, bukan angka progress UI saja.
6. Sesudah kedua review lengkap, koordinator memeriksa bukti secara semantik,
   rujukan tujuan sah, kesepakatan, identitas, serta konflik/skip. Jangan
   mengganti sampel karena hasil tidak sesuai label sumber atau harapan model.

UI tidak menampilkan subset sumber, kampanye, kategori sinyal, atau prediksi.
ID review netral dan urutan campuran dibekukan. Nama paket dan kode tetap
terlihat sehingga kebutaan terhadap reputasi paket tidak dijamin. Menu filter
MAL/HN tidak digunakan karena field subset tidak diberikan kepada UI.
Jangan bagikan `mapping.jsonl`, `pairs.jsonl` koordinator, dan prediksi model
kepada anotator sebelum review independen selesai. Jika sumber mentah diperlukan,
koordinator dapat menyiapkan salinan statis tanpa metadata sumber dan mencatat
tambahan konteks yang diberikan sama kepada kedua anotator.

## Berkas dan pemeriksaan

Direktori: `data/evaluation/mixed-dev-20261002/`.

- `annotation/pairs.jsonl`: 64 masukan UI tanpa label sumber/prediksi.
- `annotation/audit_decisions.<nama>.json`: dibuat hanya ketika manusia menyimpan
  keputusan di UI; tidak dibuat atau diisi oleh pipeline.
- `pairs.jsonl`, `mapping.jsonl`: provenance koordinator dan hubungan ID review
  dengan pair asli, lokasi sumber statis, kampanye, serta riwayat paparan.
- `selection.json`: aturan seleksi, checksum input/artefak/kode, dan batas cakupan.
- `dev-exclusions.jsonl`: nama, hash, dan kampanye yang harus dikeluarkan dari
  test/KB final, termasuk klon terkait. Belum berarti final split sudah dibuat.
- `readiness.initial.json`: pemeriksaan awal dengan nama contoh `reviewer_a` dan
  `reviewer_b`; 64 belum lengkap, `gold_ready=false`. Nama contoh bukan anotator
  yang telah ditunjuk dan tidak membuat berkas keputusan.
- `decisions-through-D85.md`: arsip dokumen keputusan sebelum D86; hash cocok
  dengan pin protokol D85. Dokumen keputusan hidup sudah bertambah D86, sehingga
  pemeriksaan pin historis harus memakai arsip ini untuk field tersebut.

Sesuaikan dua nama dengan identitas manusia yang benar-benar melakukan review:

```bash
.venv/bin/python -m pipeline.annotation_readiness \
  --cohort data/evaluation/mixed-dev-20261002 \
  --annotators nama_pertama nama_kedua
```

Skrip membaca berkas tanpa mengubah keputusan. Ia menolak satu identitas,
memeriksa kelengkapan label/catatan, bukti verbatim dengan konten perubahan,
kategori tujuan sah HN, konflik, skip, serta ID yang tidak dikenal. Status
`agreement_requires_semantic_review` tetap memerlukan pemeriksaan manusia.
Tidak ada ekspor gold otomatis atau perhitungan recall/FPR dari kandidat ini.

## Desain dan langkah setelah anotasi

MAL dipilih dari 527 kandidat yang tidak terpotong, memiliki diff 1–16.000
token sebelumnya dan pemetaan kampanye. Urutan SHA-256 `D86|campaign`, kemudian
`D86|id`; satu per kampanye, nama, hash diff, dan arsip versi. Prediksi tidak
digunakan dalam pemilihan. Urutan UI memakai SHA-256 `D86|review-order|id`.
HN persis 32 sampel D85. Kuota 32+32 menyatakan asal kandidat, bukan jumlah
malicious/benign setelah review; label akhir boleh berbeda.

Semua MAL pernah masuk D81–D84 dan HN sudah masuk D85. Karena itu dataset ini
**dev eksploratif yang telah terpapar**, bukan test independen. Kampanye MAL
mengacu clustering yang tersedia, bukan verifikasi lengkap insiden; HN belum
punya pemetaan kampanye/klon. Distribusi kecil dengan cap satu kampanye tidak
mewakili prevalensi penggunaan nyata. Hasil tidak menyelesaikan G1/G2.

Setelah anotasi/konsensus: bekukan label dan laporkan attrition, audit konteks
prompt penuh (ID baris menambah token), lalu bekukan perbandingan lima arm D85
pada dev campuran. Laporkan recall, FPR, invalid, transisi berpasangan, dan biaya
secara bersama. Hasil HN D85 yang identik dapat digunakan kembali sebagai
kontrol historis dengan asal sesi yang jelas; kebutuhan run MAL baru ditetapkan
dalam protokol inferensi berikutnya. Test final tetap harus terpisah dari dev.

Validasi implementasi: enam tes Python seleksi/kesiapan lulus, 17 tes frontend
lulus, serta typecheck dan build frontend lulus. Tidak ada panggilan LLM baru.
