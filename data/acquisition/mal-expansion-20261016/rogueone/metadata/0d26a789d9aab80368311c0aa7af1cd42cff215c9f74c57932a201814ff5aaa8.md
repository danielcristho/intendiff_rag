# xpm-tools 

xpm项目工具包

## 安装
`$ npm install xpm-tools -g` 

或 

`$ yarn global add xpm-tools`

## 参数对照表

`projectName`: 项目名称

`action`: 执行的动作,可选值为`T C D L P S`等

`T`: 测试

`C`: CSS编译

`D`: 发布项目到测试环境

`L`: 开启本地映射和反向代理

`P`: 发布项目到线上环境

`S`: 开启http-server服务

## 使用方式

1.在项目目录下使用

`$ node index.js action`

如

`$ node index.js T`

2.在非项目目录下使用

`$ node index.js projectName action`

如

`$ node index.js projectName T`
